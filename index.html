This is a Windows computer.

Download for Windows

The download starts by itself. If not, click the button.

  1. Open LabReportDesk-Setup.exe (in Downloads).
  2. If Windows shows “Windows protected your PC”: click More info → Run anyway.
  3. Click Install. Lab Report Desk opens when it's done.

This is a Mac.

Download for Mac

The download starts by itself. For Macs with an Apple chip (M1, M2, M3, M4 – almost every Mac from 2020 on). Older Mac with an Intel chip? Download for Intel Mac. (Not sure? Apple menu → About This Mac: “Chip Apple …” or “Processor … Intel”.)

This Mac looks like an Intel Mac – use the Intel link above.

  1. Open LabReportDesk-Setup.dmg (in Downloads).
  2. Drag Lab Report Desk onto the Applications folder.
  3. The first time only: open Applications, right-click (or Control-click) Lab Report Desk → Open → Open. (Needed because the app isn't registered with Apple. If the Mac only shows “Done” or “Move to Bin”: System Settings → Privacy & Security → scroll down → Open Anyway.)
  4. After that, open it normally. It runs in the menu bar (top right).

Open this page on the lab's computer (Windows or Mac). Lab Report Desk can't be installed on a phone or tablet.
